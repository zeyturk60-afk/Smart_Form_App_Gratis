# Smart Form App Gratis

## Proje Hakkında

Bu bitirme projesinde, Gratis’in form uygulamasından ilham alınarak pembe temalı ve kullanıcı dostu bir form uygulaması geliştirilmiştir. Projenin geliştirilme sürecinde Visual Studio ve SQL Server kullanılmıştır.

Uygulamada kullanıcıların form bilgilerini kolay ve anlaşılır bir şekilde girebilmesi, girilen bilgilerin veritabanında saklanması ve yönetilebilmesi amaçlanmıştır.

## Kullanılan Teknolojiler

- C#
- .NET
- Visual Studio
- SQL Server
- Windows Forms
